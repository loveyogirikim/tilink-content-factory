# 티링크 비즈레코딩 AI 홍보 콘텐츠 공장

제5회 AISH 스마트워크톤 제출작.

제품 정보와 현장·화면 사진을 넣으면 AI가 기술적 차별점을 "기능 → 고객 이익 → 근거 자료" 메시지 카드로 정리하고,
채널별 홍보 콘텐츠 초안을 만들고, 가이드라인 점검과 캠페인 성과 관리까지 한 화면에서 처리하는 웹앱입니다.

## 기능

1. **차별점 메시지 카드** — 제품 자료·사진을 AI가 읽고 카드로 정리 (근거 위치 표기)
2. **콘텐츠 생성 + 가이드라인 점검** — 블로그 리뷰·숏폼 대본·카드뉴스·검색광고 문안 초안, 필수 키워드·강조 내용·문의 정보·근거 없는 수치 점검
3. **캠페인 보드** — 기획 → 제작 → 검수 → 게시완료 칸반
4. **성과 리포트** — 콘텐츠별 UTM 발급, 문의 기록을 콘텐츠에 연결, 문의 1건당 비용, CSV 내보내기
5. **백업** — JSON 백업·복원

## 실행

서버 없이 `index.html` 파일 하나로 동작합니다.

- Claude 아티팩트로 열면 API 키 없이 AI가 동작합니다.
- 일반 웹 주소(예: Vercel, GitHub Pages)에서는 ⑤ 탭에 Claude API 키를 넣으면 브라우저에서 Anthropic으로 직접 요청합니다. 키는 해당 브라우저에만 저장됩니다.
- 키가 없으면 "예시 모드"로 정해진 문구 틀의 초안만 만듭니다 (AI 분석 아님).

## 알아둘 점

- 기본으로 들어 있는 메시지 카드 3개와 강조 내용 11개는 예시입니다. 실제 자료·가이드라인으로 바꿔 쓰세요.
- 데이터는 브라우저 저장소에 저장됩니다. 중요한 내용은 JSON 백업을 받아 두세요.
- AI 초안은 사람이 검수한 뒤 게시하세요.
